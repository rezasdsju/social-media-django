# Social Network

A social networking application where users can create profiles, share posts, and follow or unfollow other users.

## Features

- User registration with email, username, first name, and last name
- User authentication with username and password
- User profile dropdown with authenticated user information
- Secure user logout functionality

## Technologies

- Python
- Django
- JavaScript (DOM Manipulation)
- Bootstrap 5
- Tailwind CSS
- Django Crispy Forms
